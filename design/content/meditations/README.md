# תסריטי מדיטציות

התסריטים המלאים של המדיטציות. ב-v0 הוקראו בקול ממוחשב (TTS). מ-8.10 כולן בקול של מוריה רוזנברג, והתסריטים עודכנו למה שהוקלט.

## מוסכמות
- **לשון:** סתמית (לנשום, להרגיש, לשים לב), כדי שתתאים לכל מאזין ומאזינה בלי פנייה מגדרית. **בלי לוכסנים** (יודע/ת): בהקלטה אי אפשר לקרוא אותם. בגוף ראשון משתמשים בצורות שזהות בזכר ובנקבה: עבר ועתיד ("למדתי", "אבחר"), "יש לי", "חשוב לי", או רבים.
- **הפסקה:** `[שקט X שניות]`, שתיקה. המוזיקה ממשיכה.
- **שורה ריקה:** הפסקה קצרה וטבעית, 2 עד 3 שניות.
- **קצב:** איטי מאוד, בערך חצי מקצב דיבור רגיל.
- **מבחן אי-מפלגתיות:** כל תסריט עובר את המבחן שב-`CLAUDE.md` ואת "מבחן השכן" לפני הקלטה.
- **רגישות לטראומה:** בכל תסריט יש תזכורת שמותר לעצור, ועיגון בגוף בסיום.

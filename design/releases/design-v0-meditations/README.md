# תסריטי מדיטציות

התסריטים המלאים של המדיטציות. ב-v0 מקריאים אותם בקול ממוחשב (TTS), וב-v1 מורים ומורות יקליטו אותם.

## מוסכמות
- **לשון:** סתמית (לנשום, להרגיש, לשים לב), כדי שתתאים לכל מאזין ומאזינה בלי פנייה מגדרית.
- **הפסקה:** `[שקט X שניות]`, שתיקה. המוזיקה ממשיכה.
- **שורה ריקה:** הפסקה קצרה וטבעית, 2 עד 3 שניות.
- **קצב:** איטי מאוד, בערך חצי מקצב דיבור רגיל.
- **מבחן אי-מפלגתיות:** כל תסריט עובר את המבחן שב-`CLAUDE.md` ואת "מבחן השכן" לפני הקלטה.
- **רגישות לטראומה:** בכל תסריט יש תזכורת שמותר לעצור, ועיגון בגוף בסיום.

| קובץ | שם | אורך משוער |
|---|---|---|
| `behind-the-curtain.md` | מאחורי הפרגוד | כ-7 דקות |
| `clarity-in-the-noise.md` | בהירות בתוך הרעש | כ-5 דקות |
| `on-the-way-to-vote.md` | בדרך לקלפי | כ-3 דקות |
